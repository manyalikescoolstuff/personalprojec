# GetDone — Personal AI Command Center

> After a very long time, I have built something to brush up my skills with AI and try to tackle the recurring problems that I face while using AI IDEs like Antigravity.

GetDone is an intelligent, calm, and minimal personal command center for managing academic priorities, daily tasks, weekly schedules, and multi-modal brain dumps (voice, screenshots, text).

---

## Features

- 🧠 **Multi-modal Brain Dump**: Extract actionable tasks, deadlines, and schedule blocks from rough thoughts, voice notes, and screenshot uploads.
- ⚡ **AI Command Center**: Natural language query processing, smart task breakdowns, and workload easing recommendations.
- 📅 **Weekly Focus Plan**: Interactive, responsive schedule blocks with AI optimization.
- ☁️ **Firebase Backend**: Real-time multi-device sync with Cloud Firestore, Firebase Authentication, and Cloud Storage.
- ✍️ **Custom Typography**: Stylized with the unique **Hangyaboly** handwritten font.
- 🌓 **Adaptive Theming**: Tailored dark and light themes with sound feedback.

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment Variables
Copy `.env.example` to `.env.local` and add your Firebase and Gemini API keys:
```bash
cp .env.example .env.local
```

### 3. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
